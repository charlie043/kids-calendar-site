# kids-calendar-site

iPad アプリ「こども週間カレンダー」の公開ページ（GitHub Pages）。

- プライバシーポリシー: `privacy.md`
- サポート・お問い合わせ: `support.md`

## 更新が必要になるとき

アプリの名前、対応する機種や OS（iPhone 対応など）、扱うデータ（通信・収集の有無、写真の扱い）が変わったら、次を合わせて直す。

- `index.md`: アプリの説明（「iPad 用」など）
- `privacy.md`: 収集する情報・端末内に保存する情報の記述と、最終更新日
- `support.md`: 案内文
- `_config.yml`: サイトのタイトルと説明
- お問い合わせフォーム（Google フォーム）: タイトル、説明、機種と OS を聞く質問の文言と例

ページの URL（`/privacy`、`/support`）はアプリと App Store Connect に登録しているので変えない。
